# Week 2 Assessment: Indian Startups Funding Analysis

This repository contains the analysis notebook and dataset for the Week 2 Assessment on Indian Startups Funding.

## 📁 Repository Contents

- **`Week2_Assessment_RohiniNakshathra (1).ipynb`**: Jupyter Notebook containing data exploration, cleaning, analysis, and visualizations of Indian startup funding trends.
- **`indian_startups_funding.csv`**: Dataset detailing Indian startup funding transactions, including startup names, locations, industries, funding stages, amounts, funding dates, investors, and founding years.

## 📊 Dataset Schema

- **Startup Name**: Name of the startup
- **City**: Location / City of operation
- **Industry**: Sector / Industry classification
- **Funding Stage**: Stage of funding (Seed, Pre-A, Series A-E, Pre-IPO, etc.)
- **Amount**: Funding amount received
- **Funding Date**: Date of funding round
- **Investors**: Participating investors
- **Founded Year**: Year the startup was established
